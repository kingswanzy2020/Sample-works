# ADR-0005: Report audience, cadence and format

- **Status:** Proposed
- **Date:**
- **Deciders:**

## Context

A report nobody reads changes nothing. Desk heads, engineering managers and SREs need different things.

## Options considered

### Option 1: One detailed report for everyone
- **Pros:** One thing to build.
- **Cons:** Too long for managers, too shallow for engineers.

### Option 2: Summary (traffic-light per service + top 3 issues) with drill-down links
- **Pros:** 2-minute read; details available.
- **Cons:** Choosing the "top 3" is a judgement every week.

### Option 3: Live dashboard instead of a report
- **Pros:** Always current.
- **Cons:** No narrative; no weekly moment where someone has to look.

## Questions to answer before deciding

- What decision should a reader be able to make after reading it?
- Test: give the report to someone non-technical. What did they understand?
