# ADR-0004: How we know the platform helps

- **Status:** Proposed
- **Date:**
- **Deciders:**

## Context

A platform nobody uses, or that slows people down, is a cost centre. You need evidence.

## Options considered

### Option 1: Adoption count (services on the template)
- **Pros:** Easy.
- **Cons:** Mandated adoption ≠ value.

### Option 2: DORA metrics before/after (lead time, deploy frequency, change failure rate, time to restore)
- **Pros:** Industry-standard outcomes.
- **Cons:** Many factors besides the platform affect them.

### Option 3: Developer experience: time to first deploy, surveys, support-ticket volume
- **Pros:** Directly measures friction.
- **Cons:** Surveys are subjective; small samples.

## Questions to answer before deciding

- What is the one number you'd show leadership? What would make you *stop* investing in a part of the platform?
